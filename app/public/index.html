Tải dữ liệu tháng

Chọn kỳ rồi thả file vào đúng mục. Mỗi kỳ có một thư mục YYMM data chia 3 mục BANK STATEMENT, BSP và ECOM. Thư mục của kỳ mới được tạo tự động khi bạn tải file đầu tiên của kỳ đó.

    File tổng hợp tháng (mẫu AITS)

    Dùng cho các trang báo cáo. Kỳ lấy từ ô Kỳ báo cáo trong file. Khi lưu kỳ, file gốc được cất vào thư mục YYMM data của kỳ đó.

    .xlsx
    Thả file tổng hợp tháng vào đây
    File Excel (.xlsx, .xls) mẫu AITS, có sheet Tổng hợp và Tham số & tỷ giá. Thả được nhiều tháng cùng lúc.

    BANK STATEMENT Sao kê ngân hàng

    Sao kê các tài khoản nhận tiền. Nhận .xlsx, .xls, .csv, .md, .txt. Bảng có cột ngày tiền về sẽ được dùng cho tab Đối soát phí.

    Thả file sao kê vào đây hoặc bấm để chọn file0 file

    ECOM Kênh ECOM theo acquirer

    Danh sách theo thư mục ContractMD\ECOM channel. Thả báo cáo settlement, file đối soát (.xlsx, .xls, .csv) hoặc tài liệu .md vào ô của acquirer.

    BSP Kênh BSP theo acquirer

    Danh sách theo thư mục ContractMD\BSP Channel.

    Thư mục dữ liệu theo tháng

    File .zip giải nén ra đúng cấu trúc thư mục YYMM data, gồm cả các thư mục acquirer còn trống.
